# close

Finish one Bead through the native Beads lifecycle. This skill supplies the
completion gate; the installed official Beads skill and current `bd prime` guidance
own the actual issue operations, status rules, and session protocol.

## Gate and close

1. Resolve one exact Bead. Inspect its current outcome, acceptance criteria,
   relationships, discussion, and repository instructions.
2. Compare the requested boundary with observable evidence. Reuse trustworthy
   evidence already produced; run only the missing checks needed to establish the
   result. Follow any repository-specific quality or review gate.
3. Persist a compact native completion record containing the outcome, proof and
   actual results, consequential decisions, and linked follow-up work. Create native
   follow-up Beads for unfinished work that is outside the completed boundary.
4. Close through the official Beads workflow only when the acceptance boundary is
   genuinely satisfied and no unresolved blocker belongs to this Bead. Use a close
   reason that describes the achieved result.
5. Follow the repository's current session-completion instructions after closure;
   this skill adds no parallel cleanup, synchronization, or publishing protocol.

If completion cannot be proven, keep the Bead open and persist a dump-style handoff
with the exact failed check, blocker, or next action. Report the final Bead status,
evidence, follow-up IDs, and newly available work.
